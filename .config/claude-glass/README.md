# Claude Desktop glass

Same rice glass treatment as Slack, GitHub Desktop, and Steam.

- `claude-glass.css` is generated by matugen from
  `~/.config/matugen/templates/claude-glass.css`.
- `claude-glass.sh` launches the user-owned copy in
  `~/.local/share/claude-desktop` with a localhost-only DevTools port.
- `~/.local/bin/claude-desktop` shadows the system binary in PATH, so even when
  Claude rewrites its desktop entry back to `Exec=claude-desktop`, launches
  still go through the patched copy.
- `claude-glass.service` keeps the CSS and shooting-star overlay injected.
- The system package refuses `--remote-debugging-port`, so the user copy has the
  guard disabled in its `app.asar` (same-length patch, no offsets moved).

After a Claude update, quit Claude and run `refresh-app-copy.sh`, then relaunch.
